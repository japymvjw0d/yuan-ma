# BSL 风格光影 —— 生存战争插件版模组

适用于 **生存战争插件版 SurvivalcraftApi 1.9.2.1（Windows，非 mp 版）**。自用。

## 效果

| 部分 | 效果 |
| :--- | :--- |
| 地形 | 向阳面暖色、背阴面冷色（日出日落偏橙），色彩更鲜艳；阳光方向与天上的太阳一致，夜晚、下雨和暗处自动减弱 |
| 水面 | 动态波纹、阳光高光（波光粼粼）、掠射角的天空反射 |
| 全屏后处理 | 柔和泛光（亮处发光）、电影感色调曲线（中间调适度提亮、高光不过曝）、鲜艳度、轻微对比、暗角 |

- 按 **O** 开关光影，提示 `光影：开` / `光影：关`，方便对比；状态会保存，默认开启。
- 可在 **设置 → 控制 → 键盘键位** 中修改按键，名称为"光影开关"。
- 光影关闭时，画面与原版完全一致（已用像素对比验证）。

## 原理（为什么不是直接搬 MC 光影包）

MC 光影包依赖 OptiFine/Iris 的多遍延迟渲染管线和方块 ID、法线等数据，生存战争都没有，所以没法整包移植。本模组把 BSL 风格的**效果**用生存战争自己的渲染入口重新实现：

1. **替换地形着色器**：`Assets/Shaders/Opaque|AlphaTested|Transparent.vsh/.psh` 覆盖原版。
   - 法线在片元着色器里用屏幕导数重建（方块都是平面，结果精确）；
   - 保留原版的全部参数和雾计算，所以不会因为缺参数崩溃；
   - 结果按开关参数和原版结果混合。
2. **全屏后处理**：用游戏自带的 HarmonyX 接入 `ViewWidget`，先把场景画进渲染目标，再依次做亮部提取 → 1/4 分辨率高斯模糊 → 合成调色。最后仍交给原版代码贴到屏幕，所以分屏、分辨率缩放都照常工作。

出错时会自动退回原版画面，不会崩溃：
- 任何一步出错：只在日志（游戏目录 `Bugs` 文件夹）里记一条 `[ShaderMod]`，然后关闭对应部分；
- 游戏版本里找不到需要的方法：自动跳过后处理，只保留地形着色器部分。

## 编译与安装

和 SprintMod 完全相同：

1. 用 Visual Studio 打开 `ShaderMod.sln`，选 `Release`，生成解决方案。
2. 把 `ShaderMod\bin\Release\ShaderMod.scmod` 复制到游戏目录的 `Mods` 文件夹。

```
ShaderMod/
├── ShaderMod.sln
├── nuget.config
└── ShaderMod/
    ├── ShaderMod.csproj            # 引用 SurvivalcraftAPI.Survivalcraft 1.9.2.1（自带 HarmonyX）
    ├── modinfo.json
    ├── ShaderModLoader.cs          # 开关键、设置保存、每帧写入光影参数
    ├── TerrainUniforms.cs          # 太阳方向、白天强度、雨量、时间 → 地形着色器
    ├── PostProcessor.cs            # 后处理链 + Harmony 补丁
    ├── PostShaders/                # 后处理着色器（编译进 dll）
    └── Assets/
        ├── Shaders/                # 覆盖原版的地形着色器
        └── Lang/                   # 键位名称
```

## 想自己调效果？

- **后处理参数**：在 `PostProcessor.cs` 顶部：
  - `BloomStrength`：泛光强度；
  - `BloomThreshold`：多亮才发光；
  - `Exposure`：曝光；
  - `Saturation`：饱和度；
  - `Contrast`：对比；
  - `Vignette`：暗角。
- **色调曲线**：`PostShaders/Composite.psh` 里的 `k`，越大中间调越亮。
- **阳光冷暖色**：`Assets/Shaders/Opaque.psh`（和 `AlphaTested.psh` 内容相同，要一起改）里的 `warm`、`cool`。
- **水面**：`Assets/Shaders/Transparent.psh` 里的波纹频率、`160.0`（高光锐利度）、`fresnel * 0.45`（反射强度）。

改完重新生成、替换 `.scmod` 即可。

## 已知限制

- 没有实时阴影、没有真正的 HDR，属于 "BSL 风格近似"（这些需要第三档：深度纹理与阴影贴图）。
- 树叶/草不会摇曳：需要方块 ID，生存战争的地形数据里没有。
- 冰等其他半透明方块的顶面也会有少量水面波光。
- 与其他替换 `Shaders/Opaque|AlphaTested|Transparent` 的模组或材质包冲突，后加载的生效；此时本模组的地形部分自动不生效，后处理仍然工作。

## 游戏内测试清单

1. 进入存档，白天：阳光照到的面偏暖、背阴面偏冷，整体更鲜艳，亮处（天空、白色方块）有柔和泛光，屏幕四角略暗。
2. 按 **O**：提示 `光影：关`，画面变回原版；再按 O 恢复。
3. 看水面：有波纹闪光，对着太阳方向能看到高光，远处水面更像反射天空。
4. 日出/日落时阳光面偏橙；夜晚和下雨时阳光效果明显减弱；漆黑的洞穴、室内暗处没有阳光冷暖色（火把照亮的地方会有轻微冷暖色，因为游戏把天光和方块光烘焙在一起，区分不开）。
5. 设置里切换"分辨率"为低/中/高，画面都正常；帧率可接受。
6. 打开背包、在输入框打字时按 O 没有反应。
7. 退出重进游戏，光影开关状态保持。
